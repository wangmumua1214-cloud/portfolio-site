# 个人作品站

个人作品集网站，用于展示作品、个人简介与联系方式。

## 定位

视觉与交互参考 [morevfx.com](https://www.morevfx.com)：深色基调、大量留白、作品以大图/视频铺满视野，
滚动驱动的分段叙事，克制的动效，不用花哨的模板感 UI。

## 内容结构

- **作品（Works）** — 核心模块，按四类分组：
  - 传统 CG
  - UE（虚幻引擎）
  - AI 视频
  - 程序化开发
- **简介（About）** — 个人介绍、技能与工具、经历
- **联系方式（Contact）** — 邮箱与社交/平台链接

## 技术要求

- 纯前端，可静态托管（GitHub Pages / 任意静态服务）
- 移动端可用：桌面为多列大图，移动端单列
- 作品条目支持视频与图片，视频不做自动播放声音，需用户点击
- 首屏加载要快：图片懒加载，视频用 poster 占位

## 待定

- 技术栈（原生 HTML/CSS/JS 或 Vite 起项目均可）
- 作品素材来源与命名规范
- 是否需要后台（用于自助上传作品）

## 开发约定

- 主分支 `main`，改动走分支 + Pull Request，不直接推 main
- 提交信息用中文或英文均可，一行说清做了什么
- 不提交 `node_modules`、构建产物、`.env` 及任何密钥
